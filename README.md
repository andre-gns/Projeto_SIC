### Desenvolvimento de um RPA para Normalização de Produtos em Site de Vendas


Estou desenvolvendo um RPA (Robotic Process Automation) em Python com o objetivo de automatizar a extração e normalização de produtos a partir de uma planilha Excel para um site de vendas.

🔹 Objetivo do RPA:<br>
1️⃣ Ler e extrair informações de uma planilha Excel contendo os produtos.<br>
2️⃣ Formatar e normalizar os dados, garantindo que os produtos atendam aos padrões exigidos pelo site de vendas.<br>
3️⃣ Automatizar a inserção dos produtos no site, reduzindo o tempo e erros manuais.  

🔹 Tecnologias Utilizadas:<br>
✅ Python – Linguagem principal para o desenvolvimento. <br>
✅ Pandas/OpenPyXL – Para manipulação e leitura de arquivos Excel.<br>
✅ Selenium/PyAutoGUI – (Previstos) Para interação com o site de vendas.<br>

🔹 Status Atual:<br>
O desenvolvimento foi iniciado e a estrutura básica do código já foi implementada. O projeto atualmente está na etapa de leitura do arquivo Excel, onde estou lidando com a extração correta dos dados para garantir uma padronização eficiente antes do envio ao site.

Nos próximos passos, será integrada a automação da interface web para finalizar o processo de normalização dos produtos. 🚀
